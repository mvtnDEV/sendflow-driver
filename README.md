# SendFlow Driver — App del Conductor

PWA móvil para conductores de reparto. Permite escanear QR, gestionar entregas y subir evidencia fotográfica.

## Stack
- Next.js 14 + TypeScript
- jsQR (escáner de cámara)
- PWA (instalable en iOS y Android)

## Setup local

```bash
npm install
npm run dev
# Abre en http://localhost:3001
```
